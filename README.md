# Bài tập kiểm tra 2: Quản lý sinh viên bằng LINQ to XML

## Mô tả dự án
Chương trình viết bằng ngôn ngữ **C#** (Console Application) thực hiện các chức năng đọc và truy vấn dữ liệu sinh viên trực tiếp từ file **`students.xml`** sử dụng thư viện **LINQ to XML** (`System.Xml.Linq`).

## Yêu cầu hệ thống
- .NET SDK (phiên bản .NET Core / .NET 6.0 hoặc cao hơn).
- IDE lập trình: Visual Studio hoặc Visual Studio Code.

## Hướng dẫn chạy chương trình
1. Tạo một project C# Console Application mới.
2. Đặt file **`students.xml`** vào thư mục chứa mã nguồn hoặc cùng thư mục với file thực thi (`bin/Debug/...`).
3. Sao chép toàn bộ mã nguồn trên vào file **`Program.cs`**.
4. Chạy chương trình (nhấn `F5` trên Visual Studio hoặc gõ lệnh `dotnet run` trong Terminal).
5. Sử dụng giao diện Menu tương tác từ `1` đến `15` để xem kết quả các yêu cầu, hoặc nhấn `0` để thoát.
